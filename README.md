# Hogwarts Voice Caster RU — v0.3.0

**Офлайн голосовые заклинания для Hogwarts Legacy с приоритетом скорости.**

Произнеси «Люмос», «Акцио» или «Экспеллиармус» — программа
распознаёт русский голос на ПК и передаёт команду в игровой мод
[SpellCaster](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster).

**Статус:** прототип. Автоматические тесты Windows/Linux выполнены.
Задержка в реальной игре, качество распознавания голоса и совместимость
с микрофоном пользователя ещё не проверены. Абсолютный ноль задержки невозможен.

## Быстрый старт

1. Нужны Windows 10/11, PC-версия Hogwarts Legacy, микрофон, Python 3.11 x64.
2. Установи внутриигровой мод UE4SS SpellCaster из
   [релизов автора](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster/releases).
   Оригинальное десктоп-приложение SpellCaster оставь закрытым.
3. Скачай этот репозиторий через **Code → Download ZIP** и распакуй.
4. Запусти **install.bat**. Он установит Vosk, sounddevice, NumPy и скачает
   русскую модель Vosk small-ru-0.22. Интернет нужен только при установке.
5. Запусти **run.bat**, выбери микрофон и оставь **Максимальная скорость**.
6. Нажми **Проверить распознавание без игры**. Проверь срабатывание
   названий команд в консоли на собственном произношении.
7. Открой сохранение Hogwarts Legacy. Затем нажми в программе
   **Начать колдовать**, вернись в игру и произноси заклинания.
   F8 — поставить распознавание на паузу.

**Не нужно записывать голос, создавать профиль или подтверждать владельца.**
В версии 0.3 это отключено по умолчанию ради скорости.

## Почему должно быть быстрее

- Распознавание речи полностью локальное: нет облачного запроса.
- Частичные гипотезы Vosk принимаются немедленно, до окончания тишины.
- Аудио поступает блоками по 20 миллисекунд (вместо 32 мс).
- В режиме **Максимальная скорость** не требуется второе подтверждение
  того же слова. **Сбалансированный** использует 32 мс и 2 подтверждения.
- Идентификация человека по голосу полностью выключена по умолчанию.
- Передача SpellCaster происходит через общую память без эмуляции
  клавиатурных комбинаций и без смены панели заклинаний.
- Повтор одного заклинания ограничен по времени, но первое не задерживается.

**Внимание:** блок в 20 мс — это размер аудиоданных, а не обещанная
задержка в 20 мс. Для распознавания нужна достаточная часть слова;
игра реагирует на команду отдельным кадром. Быстрый режим увеличивает
риск ложных распознаваний.

## Замеры задержки

Включена диагностика debug_latency=true. Пример строки:

~~~text
[sent] Lumos | last-audio-to-dispatch=21.3ms, onset-to-dispatch~428ms
~~~

Числа выше — **только пример формата**, не результаты испытаний.

- last-audio-to-dispatch: время между последним полученным аудиоблоком
  и передачей команды в память мода, **не полная задержка речи**.
- onset-to-dispatch: грубая оценка с начала слышимого звука до отправки
  команды. Включает время произнесения слова и зависит от шума.
- Время воспроизведения анимации в Hogwarts Legacy не измеряется.

Для калибровки произношения предусмотрена кнопка в главном окне.
Она показывает 28 карточек с русскими названиями, английскими именами
и **оригинальными рисунками символов**. Можно записывать несколько попыток
и сохранять только подтверждённые распознанные фразы — аудиофайлы
не сохраняются. Это добавляет фразы в словарь, но **не обучает Vosk
распознавать совершенно новые звуки**.

## Настройки

Файл config.json:

~~~json
{
  "samplerate": 16000,
  "block_ms": 20,
  "stable_partial_updates": 1,
  "min_gap_ms": 0,
  "repeat_gap_ms": 450,
  "mic_device": null,
  "require_game_focus": true,
  "push_to_talk": false,
  "verbose": false,
  "grammar_mode": "constrained",
  "speaker_verification": false,
  "speaker_threshold": 0.68,
  "debug_latency": true,
  "performance_mode": "fast"
}
~~~

- require_game_focus=true: кастование только при активном окне Hogwarts Legacy.
- push_to_talk=true: говорить, удерживая F9.
- verbose=true: показывает промежуточно распознанные слова.
- grammar_mode=constrained: ограниченный набор заклинаний;
  free: обычный словарь Vosk. Если вымышленное слово вообще не
  понимается, переключение режима не гарантирует исправления.
- speaker_verification=false: **рекомендуемый быстрый режим**.

Изменения настроек вступают в силу после остановки и нового запуска
распознавания.

## Дополнительная проверка голоса — только по желанию

Функция проверки говорящего **не входит в быстрый путь**.
Чтобы включить её, сначала установи зависимости через
**install-voice-id.bat**, запиши голосовые отпечатки в мастере,
затем поменяй speaker_verification на true в config.json.
Проверка Resemblyzer может замедлять кастование и ошибаться
на коротких словах (например, «Нокс»).
Отпечатки хранятся локально и тоже являются биометрическими данными.
Голосовой профиль не гарантирует защиту от воспроизведения записи голоса.

**Переключение отдельных профилей для двух людей — будущая функция,
в версии 0.3 пока не реализовано.** Приоритет — быстрое распознавание.

## Команды для проверки

~~~bat
run.bat --dry-run
run.bat --listen
run.bat --list-mics
run.bat --send Lumos
~~~

Последняя команда проверяет IPC напрямую, без микрофона.
Не запускай одновременно два десктоп-клиента общего канала SpellCaster.

Для проверки тестов:

~~~bat
set PYTHONPATH=src
python -m unittest discover -s tests -v
~~~

## Ограничения и лицензии

Для кастования пока нужен внутриигровой компонент оригинального
[HogwartsLegacy-SpellCaster](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster),
потому что полностью самостоятельный UE4SS-мод нами не создан.
Вымышленные названия заклинаний могут неправильно распознаваться
обычной русской моделью Vosk. Звуки игры через колонки тоже могут
вызвать случайное срабатывание — наушники рекомендованы.
