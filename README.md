# Hogwarts Voice Caster RU — v0.5.0

**Офлайн голосовые заклинания для Hogwarts Legacy с приоритетом скорости.**

Произнеси «Люмос», «Акцио» или «Экспеллиармус» — программа
распознаёт русский голос на ПК и передаёт команду в игровой мод
[SpellCaster](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster).

**Статус:** прототип. Автоматические тесты Windows/Linux выполнены.
Задержка в реальной игре, качество распознавания голоса и совместимость
с микрофоном пользователя ещё не проверены. Абсолютный ноль задержки невозможен.

## Быстрый старт

1. Нужны Windows 10/11, PC-версия Hogwarts Legacy, микрофон, Python 3.11 x64.
2. Установи внутриигровой мод UE4SS SpellCaster из
   [релизов автора](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster/releases).
   Оригинальное десктоп-приложение SpellCaster оставь закрытым.
3. Скачай этот репозиторий через **Code → Download ZIP** и распакуй.
4. Запусти **install.bat**. Он установит Vosk, sounddevice, NumPy и скачает
   русскую модель Vosk small-ru-0.22. Интернет нужен только при установке.
5. Запусти **run.bat**, выбери микрофон и оставь **Максимальная скорость**.
6. Нажми **Проверить распознавание без игры**. Проверь срабатывание
   названий команд в консоли на собственном произношении.
7. Открой сохранение Hogwarts Legacy. Затем нажми в программе
   **Начать колдовать**, вернись в игру и произноси заклинания.
   F8 — поставить распознавание на паузу.

**Не нужно записывать голос, создавать профиль или подтверждать владельца.**
В версии 0.3 это отключено по умолчанию ради скорости.

## Почему должно быть быстрее

- Распознавание речи полностью локальное: нет облачного запроса.
- Частичные гипотезы Vosk принимаются немедленно, до окончания тишины.
- Аудио поступает блоками по 20 миллисекунд (вместо 32 мс).
- В режиме **Максимальная скорость** не требуется второе подтверждение
  того же слова. **Сбалансированный** использует 32 мс и 2 подтверждения.
- Идентификация человека по голосу полностью выключена по умолчанию.
- Передача SpellCaster происходит через общую память без эмуляции
  клавиатурных комбинаций и без смены панели заклинаний.
- Повтор одного заклинания ограничен по времени, но первое не задерживается.

**Внимание:** блок в 20 мс — это размер аудиоданных, а не обещанная
задержка в 20 мс. Для распознавания нужна достаточная часть слова;
игра реагирует на команду отдельным кадром. Быстрый режим увеличивает
риск ложных распознаваний.

## Замеры задержки

Включена диагностика debug_latency=true. Пример строки:

~~~text
[sent] Lumos | last-audio-to-dispatch=21.3ms, onset-to-dispatch~428ms
~~~

Числа выше — **только пример формата**, не результаты испытаний.

- last-audio-to-dispatch: время между последним полученным аудиоблоком
  и передачей команды в память мода, **не полная задержка речи**.
- onset-to-dispatch: грубая оценка с начала слышимого звука до отправки
  команды. Включает время произнесения слова и зависит от шума.
- Время воспроизведения анимации в Hogwarts Legacy не измеряется.

Для калибровки произношения предусмотрена кнопка в главном окне.
Она показывает 28 карточек с русскими названиями, английскими именами
и **оригинальными рисунками символов**. Можно записывать несколько попыток
и сохранять только подтверждённые распознанные фразы — аудиофайлы
не сохраняются. Это добавляет фразы в словарь, но **не обучает Vosk
распознавать совершенно новые звуки**.

## Настройки

Файл config.json:

~~~json
{
  "samplerate": 16000,
  "block_ms": 20,
  "stable_partial_updates": 1,
  "min_gap_ms": 0,
  "repeat_gap_ms": 450,
  "mic_device": null,
  "require_game_focus": true,
  "push_to_talk": false,
  "verbose": false,
  "grammar_mode": "constrained",
  "speaker_verification": false,
  "speaker_threshold": 0.68,
  "debug_latency": true,
  "performance_mode": "fast"
}
~~~

- require_game_focus=true: кастование только при активном окне Hogwarts Legacy.
- push_to_talk=true: говорить, удерживая F9.
- verbose=true: показывает промежуточно распознанные слова.
- grammar_mode=constrained: ограниченный набор заклинаний;
  free: обычный словарь Vosk. Если вымышленное слово вообще не
  понимается, переключение режима не гарантирует исправления.
- speaker_verification=false: **рекомендуемый быстрый режим**.

Изменения настроек вступают в силу после остановки и нового запуска
распознавания.

## Дополнительная проверка голоса — только по желанию

Функция проверки говорящего **не входит в быстрый путь**.
Чтобы включить её, сначала установи зависимости через
**install-voice-id.bat**, запиши голосовые отпечатки в мастере,
затем поменяй speaker_verification на true в config.json.
Проверка Resemblyzer может замедлять кастование и ошибаться
на коротких словах (например, «Нокс»).
Отпечатки хранятся локально и тоже являются биометрическими данными.
Голосовой профиль не гарантирует защиту от воспроизведения записи голоса.

**Переключение отдельных профилей для двух людей — будущая функция,
в версии 0.3 пока не реализовано.** Приоритет — быстрое распознавание.

## Команды для проверки

~~~bat
run.bat --dry-run
run.bat --listen
run.bat --list-mics
run.bat --send Lumos
~~~

Последняя команда проверяет IPC напрямую, без микрофона.
Не запускай одновременно два десктоп-клиента общего канала SpellCaster.

Для проверки тестов:

~~~bat
set PYTHONPATH=src
python -m unittest discover -s tests -v
~~~

## If install.bat closes immediately
Earlier versions accidentally used Unix LF endings, which may break cmd.exe.
Download the latest ZIP again and EXTRACT it to a folder before opening install.bat.
The updated script uses Windows CRLF and pauses on both success and failure.
It also writes install.log next to the script, including details about failures.
The fast mode needs only install.bat; optional voice ID is installed separately.
If it still closes, open a Command Prompt in the extracted folder and run:

```bat
cmd /d /k install.bat
```



If the log shows `[ERROR] No runtime installed that matches 3.11`, the `py` launcher exists
but Python 3.11 itself is not installed. Run `py install 3.11` in a normal Windows
terminal, or install 64-bit Python 3.11/3.12 from python.org. The installer
now checks actual Python stdout, handles misleading launcher exit codes, and
falls back to an existing supported interpreter if available. You can check
without installing anything via `install.bat --check-python`.

## Приложение v0.4: новый интерфейс, без открытого терминала

После обновления скачай ZIP репозитория, распакуй и **повторно запусти
install.bat**. Установятся графические зависимости CustomTkinter и Pillow.
Теперь двойной щелчок по **run.bat** открывает приложение через
pythonw.exe — окно командной строки не остаётся открытым. При ошибке
запуска появится сообщение, а подробности запишутся в
`%LOCALAPPDATA%\HogwartsVoiceCasterRU\startup_error.log`.

Кнопка **«Проверить микрофон»** теперь ведёт журнал распознавания в
главном окне. Отдельный терминал для этой проверки не открывается.
«Начать колдовать» запускает тот же скрытый процесс с передачей
заклинаний в игру. «Остановить» завершает этот процесс.

### Настоящие иконки вместо случайных символов

Изображения не генерируются. В меню заклинаний показываются оригинальные
PNG из игры после локального импорта. Авторские права на игровые изображения
остаются у правообладателей; **мы не загружаем их в репозиторий**.

1. Открой в боковом меню **«Источник иконок»** — откроется набор
   Spells для Hogwarts Legacy на The Spriters Resource:
   https://www.spriters-resource.com/pc_computer/hogwartslegacy/asset/494960/
2. Скачай **ZIP** с набором заклинаний на свой ПК.
3. В программе нажми **«Импорт игровых иконок»**, выбери ZIP.
   Программа сама найдёт файлы `Spells/UI_T_accio.png`,
   `UI_T_lumos.png`, `UI_T_expelliarmus.png` и остальные.
4. Они появятся на карточках и будут храниться только локально по адресу
   `%LOCALAPPDATA%\HogwartsVoiceCasterRU\spell_icons`.

В указанном наборе нашлось 26 соответствующих игровых иконок;
Nox и AppareVestigium не представлены отдельными значками, поэтому
программа честно показывает отсутствие изображения, а не
подменяет его случайной картинкой.

Программа работает и без импорта изображений, но карточки
будут с аккуратными заглушками без выдуманных символов.

**Примечание:** запуск через CLI `run.bat --dry-run` по-прежнему
показывает консоль для диагностики; обычный `run.bat` — без неё.


## Исправление ошибки `Failed to create a model` (Windows)

У Windows-сборки Vosk возможна ошибка при чтении пути с кириллицей.
Теперь установщик хранит русскую модель в ASCII-пути в LocalAppData,
а при необходимости — в общей пользовательской папке Windows.
Старая модель из `models/` переносится автоматически без повторной загрузки,
если она исправна. `install.bat` проверяет модель реальной загрузкой через Vosk;
при ошибке повторно скачивает официальную модель. Если в журнале
снова появилось `Failed to create a model`, просто запусти
**обновлённый** `install.bat` (это не удаляет настройки профиля и игры).

Модель больше не обязана храниться внутри папки GitHub-архива.
Для установки на ПК с русским именем Windows требуется хотя бы одна
доступная для записи папка с ASCII-путём из LOCALAPPDATA,
PROGRAMDATA или PUBLIC. Сообщения о диагностике сохраняются в `install.log`.


## Обучение произношению: v0.5

Предыдущая версия не умела учиться звучанию слов: кнопка записи только
проверяла догадку общего Vosk. Теперь запись сохраняет акустические
признаки выбранного заклинания независимо от распознанного текста.

1. Открой «Тренировка заклинаний», выбери «Акцио».
2. Нажми «Записать образец голоса», после сигнала произнеси «Акцио».
3. Повтори три раза до сообщения «Обучено».
4. Сделай то же самое для «Левиосо» и других нужных заклинаний.
5. В главном окне нажми «Проверить микрофон» и говори их по одному.
6. Ищи в журнале строки [trained] Accio: similarity=..., а затем [TEST] Accio.
7. Проверь также посторонние слова: важно выявить ложные срабатывания.

ВНИМАНИЕ: текст «Vosk услышал: не разобрано» больше не мешает обучению
акустического шаблона. Кнопка «Запомнить этот вариант» относится только
к текстовым алиасам и теперь необязательна. Не подтверждай неверную догадку Vosk.

Новые образцы находятся в локальном файле:
%LOCALAPPDATA%\HogwartsVoiceCasterRU\pronunciation_templates.json
Там сохраняются только спектральные признаки, а не аудиозаписи WAV/PCM.
Такие признаки тоже относятся к персональным данным — не выкладывай их.

При наличии трёх образцов одного заклинания программа сравнивает новые
произнесения с ними после короткой тишины около 100 мс. Для обученных
слов этот результат имеет приоритет перед догадкой Vosk. Для пока
необученных слов используется Vosk, но в смешанном режиме его ответ
может задерживаться до конца короткой речи. Если нет обученных слов,
сохраняется прежний быстрый режим на частичных гипотезах Vosk.

Экспериментальные параметры — template_threshold (0.78) и
template_margin (0.055) в config.json. Это не доказанная точность.
Слишком высокий порог пропускает команды, слишком низкий даёт ложные.
Проверять надо на реальном микрофоне, с примерами похожих слов и шума.

Фразу «путь к цели» удалили из общего словаря, поскольку она
провоцировала подмену «Акцио». Теперь AppareVestigium обозначается
вариантом «аппаре вестигиум».
