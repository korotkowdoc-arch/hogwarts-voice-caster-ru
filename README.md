# Hogwarts Voice Caster RU — прототип 0.1.0

**Голосовое применение заклинаний в Hogwarts Legacy на Windows.**
Произнеси «Люмос», «Конфринго» или «Авада Кедавра» — компаньон
локально распознаёт русскую речь и отправляет название заклинания
в **UE4SS-мод SpellCaster** через разделяемую память Windows.

**Важно:** это самостоятельный экспериментальный клиент распознавания,
а не готовый проверенный релиз. Код проверен автоматическими тестами,
но работа в Hogwarts Legacy и на Windows с реальным микрофоном **ещё не проверена**.
Не обещаем нулевую задержку или безошибочное распознавание всех заклинаний.

## Зачем так, а не отправлять `1` / `2` / `3` / `4`

Существующий [HogwartsLegacy-SpellCaster (MIT)](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster)
умеет применять заклинание напрямую через `WandTool` игрового персонажа.
Наш клиент пишет команду в совместимый с ним общий буфер
`SpellCasterSharedMemory`. **Занимать слоты панели ради голосового
заклинания не нужно.** Игровые ограничения/кулдауны остаются на стороне
мода и игры. Никаких модификаций сохранений или кода Steam-клиента.

**Требования:** Windows 10/11 x64, PC-версия Hogwarts Legacy, микрофон,
Python 3.11/3.12 x64, интернет при первой установке, установленный
UE4SS-компонент SpellCaster.

## Установка (один раз)

1. Установи PC-версию **Hogwarts Legacy**.
2. Открой [Releases SpellCaster](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster/releases).
   Скачай подходящий актуальный релиз SpellCaster от оригинального автора.
   Запусти его установщик/приложение и **поставь UE4SS/SpellCaster-мод
   в папку игры** по инструкциям автора. После установки **закрой
   оригинальное приложение SpellCaster** (не держи два клиента одновременно).
   Не скачивай `.exe` с неофициальных зеркал.
3. Установи [Python 3.11 x64](https://www.python.org/downloads/) с `Add Python to PATH`.
4. Скачай ZIP этого репозитория (или `git clone`), распакуй в любую папку.
5. Запусти двойным кликом `install.bat`. Он создаст `.venv`, поставит
   `vosk` и `sounddevice`, скачает **официальную небольшую русскую модель**
   [Vosk small-ru-0.22](https://alphacephei.com/vosk/models). Модель (Apache 2.0)
   загружается только при установке, во время игры интернет не нужен.
6. Запусти `run.bat --dry-run`, несколько раз произнеси заклинания.
   Посмотри `[heard]` и `[TEST]`. Только после проверки включай отправку в игру.
7. Запусти Hogwarts Legacy, загрузись в сохранение. Убедись, что
   SpellCaster UE4SS-мод загружен. Оставь игру на переднем плане.
8. Запусти `run.bat` и говори заклинания. F8 — пауза/возобновление.

Если вместо `[OK]` появляется `game mod not responding (consumer heartbeat)`,
значит UE4SS-компонент не работает / не загружен / не присылает heartbeat.
Запуск оригинальной программы SpellCaster одновременно с нашей **не нужен**.
Проверь логи UE4SS и установку в папку игры. Если прямой протокол
изменился в новом релизе SpellCaster, потребуется адаптация клиента.

команды определяется установленной версией игрового мода.

### Быстрая серия заклинаний

Обрабатываются **частичные** результаты распознавания (ещё до
финального подтверждения тишины). При непрерывном
«Акцио, Инсендио» парсер может выдать оба заклинания в одной речевой
последовательности. Ограничение частоты и защита от дублирования
управляются в `config.json`.

**Нулевой задержки не бывает.** Нужно физическое время, чтобы произнести
достаточно звуков для распознавания. Конкретную задержку в миллисекундах
пока не измеряли. Для уменьшения задержки `block_ms=32` (512 семплов
при 16 кГц), `stable_partial_updates=2`. `stable_partial_updates=1`
срабатывает раньше, но может увеличивать число ложных команд.
Это не гарантия FPS, реакции игры или скорости модели на твоём ПК.

## Настройки

Открой `config.json` текстовым редактором:

```json
{
  "samplerate": 16000,
  "block_ms": 32,
  "stable_partial_updates": 2,
  "min_gap_ms": 0,
  "repeat_gap_ms": 500,
  "mic_device": null,
  "require_game_focus": true,
  "push_to_talk": false,
  "verbose": true,
  "grammar_mode": "constrained"
}
```

- `mic_device`: номер микрофона из `run.bat --list-mics`; `null` — системный.
- `require_game_focus=true`: команды отправляются только при активном
  окне `HogwartsLegacy.exe` / `Phoenix-Win64-Shipping.exe`.
- `push_to_talk=true`: команда распознаётся только при **удержании F9**.
- `grammar_mode=constrained`: Vosk ограничивает словарь фразами заклинаний.
  Если редкие имена вообще не распознаются, попробуй `free` и добавь
  фактически услышанные варианты из `[heard]` в `spells.json`.
- `verbose=true`: выводит промежуточное распознавание для диагностики.
- Если не работает аудиоустройство 16 кГц, выбери другой микрофон в Windows.

Мод может среагировать на слова в игре или от других людей. Для
стримов и колонок рекомендуется **наушники** и `push_to_talk=true`,
если ложные применения мешают.

### Проверка и диагностика

```bat
run.bat --list-mics
run.bat --dry-run
run.bat --send Lumos
```

`--send Lumos` отправляет команду в мод напрямую без микрофона —
удобно проверить IPC отдельно от распознавания.

## Тесты (без Windows/игры)

```bat
set PYTHONPATH=src
python -m unittest discover -s tests -v
```

Тестируются фразы, серии заклинаний, защита от дублей и формат кольцевого
буфера IPC. Достоверно оценить скорость, качество речи и совместимость
UE4SS можно только на ПК с установленной игрой и микрофоном.

## Известные ограничения

1. **Это не автономный UE4SS-мод:** требуется UE4SS-компонент оригинального
   SpellCaster. Он и непосредственно вызывает магию в игре.
2. **Словарь Vosk не обучен специально под имена заклинаний.**
   Некоторые редкие названия могут распознаваться плохо/не распознаваться
   из-за отсутствия фонетических записей в модели. Изменение `spells.json`
   исправляет только варианты уже распознаваемых слов. Для надёжного
   полного набора потребуется специализированная акустическая модель
   либо пользовательская калибровка произношения.
3. Мгновенное переключение/применение решает UE4SS; реальная
   доступность заклинания зависит от игровой логики.
4. Не запускай два производителя команд в одноименную общую память:
   наша программа и оригинальное приложение SpellCaster **одновременно**
   могут конфликтовать (протокол single-producer/single-consumer).
5. Это Windows-only и рассчитано на **однопользовательскую** Hogwarts Legacy;
   другие моды, игра с античитом и онлайн-процессы не тестировались.
