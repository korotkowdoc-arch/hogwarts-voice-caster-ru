# Hogwarts Voice Caster RU v1.1.0

Голосовое применение заклинаний в Hogwarts Legacy (ПК, Windows). **Новый
основной движок — русская нейросеть GigaAM v2, работающая локально через
sherpa-onnx.** Старое сравнение DTW и словарь Vosk больше не участвуют
в применении заклинаний в стандартной конфигурации.

Это экспериментальная версия: программа и тесты проверены, но насколько
правильно нейросеть распознает именно твои произнесения «Люмос», «Акцио»
и других вымышленных слов, ещё нужно проверить на твоём микрофоне.
Нулевая задержка невозможна; узнаем реальное время в журнале.

## Установка

1. На ПК должны быть Windows 10/11 x64, Python 3.11/3.12 x64 и микрофон.
2. В Hogwarts Legacy должен быть установлен внутриигровой UE4SS-компонент
   [SpellCaster](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster).
   Оригинальный десктоп-клиент SpellCaster оставь закрытым.
3. Скачай этот репозиторий через **Code → Download ZIP**, распакуй
   **в новую папку**, затем запусти **install.bat**.
4. Установщик добавит пакет sherpa-onnx и скачает нейромодель (~236 МБ) из
   официального опубликованного набора sherpa-onnx. SHA256 модели проверяется.
   Скачивание происходит **один раз** в локальное хранилище и не повторяется,
   если файл уже в порядке. Это не облачное распознавание — интернет нужен
   только для установки.
5. Запусти **run.bat**. При обычном запуске терминал не остаётся открытым.

Если установка сообщит об ошибке, приложи **install.log** из папки
проекта. Старые обучающие образцы не нужно удалять — новый режим их не
использует.

## Проверка без игры

Сначала в главном окне выбери свой микрофон. Режим активации —
**«Удерживать кнопку (1 заклинание)»**. По умолчанию F9, можно выбрать
Mouse4 или Mouse5. Нажми **«Проверить микрофон»** и сделай пять
проверок:

1. Зажми назначенную кнопку (например, Mouse5).
2. Произнеси **«Люмос»**.
3. Отпусти кнопку.

Журнал должен показать:
- \`[ptt] RECORDING\` и \`[ptt] RELEASED ...\` — запись работает;
- \`[heard] люмос\` — **настоящий текст, который услышала нейросеть**;
- \`[TEST] Lumos\` — заклинание сопоставлено, но в игру НЕ отправлено;
- либо \`[blocked]\` — не распознано уверенно, команда не отправлена.

Затем попробуй «Акцио» и посторонние слова. Если нейросеть вернула
«люмос» только при произнесении «Люмос», а чужие слова блокируются —
это хороший признак. Если она слышит иное слово, пришли именно строки
\`[heard]\` и \`[asr]\` — будем улучшать соответствие звучания,
а не гадать по бессмысленному порогу DTW.

**По умолчанию разрешены только Lumos и Accio.** Это сознательное
ограничение на первом этапе, чтобы случайное «невидимость» не отправило
другое заклинание. Перечень \`enabled_spells\` находится в config.json,
все допустимые названия — в spells.json. При добавлении новых
заклинаний используй русское написание, которое произносишь, и
сначала проверь его без игры. Обычные слова вроде «невидимость»
намеренно НЕ являются заклинаниями в новом движке.

## Применение в Hogwarts Legacy

Когда проверка без игры работает, запусти игру через Epic или Steam,
загрузи сохранение, в нашем приложении нажми **«Начать колдовать»**
и вернись в игру.

Удерживай назначенную кнопку, произноси одно заклинание, отпускай.
После отпускания программа проверяет нейросетевой текст и только
потом отправляет команду в игровой мод. F8 — пауза.
В журнале видно время \`release-to-dispatch\` для каждого применения.

Чтобы убедиться в связи с модом, в PowerShell из папки приложения
можно выполнить:

~~~powershell
.\run.bat --send Lumos
~~~

Это обходит микрофон и нейросеть и проверяет только игровое соединение.

## Почему раньше не работало

Предыдущий Vosk подбирал «моментум» или «невидимость» вместо «Люмос».
Потом мы сделали локальные шаблоны MFCC+DTW по трём записям, но на
живой речи оценки оказались слишком низкими. Теперь используется
предобученная на русском языке **GigaAM v2**. Ей не требуется
обучение на собственном голосе. PTT оставлен для точной границы
одной команды.

Ключевое ограничение: **GigaAM тоже может ошибиться на вымышленном
слове**. Для предотвращения лишнего применения команда проходит
строгую проверку по списку допустимых названий, без принудительного
выбора «похожего» заклинания. Короткие слова требуют точного
совпадения с настроенным вариантом произношения; для длинных
названий допускается минимальная опечатка. Если совпадения нет,
ничего не применяется.

## Лицензия и модели

Код нашей программы — MIT. Внутриигровой SpellCaster —
сторонний мод с собственным репозиторием.

GigaAM v2 разработана [Salute Developers](https://github.com/salute-developers/GigaAM).
Преобразованная ONNX-модель распространяется через
[sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/offline-ctc/nemo/russian.html)
и [Hugging Face](https://huggingface.co/csukuangfj/sherpa-onnx-nemo-ctc-giga-am-v2-russian-2025-04-19).
Весовые файлы в GitHub-проект не включены и скачиваются только
при установке. У модели есть отдельные лицензионные ограничения,
которые нужно соблюдать; проект предназначен для личного
некоммерческого использования.

Нейросеть работает на CPU, без CUDA/видеокарты, в одном
выделенном рабочем потоке. Приложение не записывает голос на диск
при применении команд и не отправляет его в интернет.

## Разработка и тесты

GitHub Actions запускает проверки Python, интерфейса и сборки на Windows
и Linux. Проверка Windows также загружает настоящую модель GigaAM v2 и
пытается открыть её и выполнить тест на тишине, чтобы выявлять ошибки
совместимости. **Это не проверка качества распознавания «Люмос»
на голосе пользователя.**

Старые движки Vosk и DTW сохранены в коде только для диагностики.
По умолчанию используется \`"recognition_engine": "gigaam_ru"\`.


## v1.0.1 — проверка всех заклинаний и разрешения в интерфейсе

По результатам живой проверки GigaAM верно услышала `депульсо` и
`экспелярмус`, но игра не применяла их: в v1.0 были разрешены только
Lumos и Accio. Исправлено разделение двух режимов:

- **«Проверить микрофон»** теперь распознаёт **все 28** заклинаний по
  словарю, но не отправляет ничего в игру. Это позволяет проверить
  каждое произношение безопасно.
- В боковом меню появился раздел **«Доступные заклинания»** с
  переключателями для каждой команды и кнопками разрешить/запретить все.
  Выбранные разрешения применяются **только в игровом режиме** и
  сохраняются в `config.json` как `enabled_spells`.
- Нейросеть выдала вариант `экспелярмус`, который теперь явно
  сопоставляется с `Expelliarmus`. Это не снижает порог и не включает
  неограниченное нечёткое угадывание.
- Текст `невидимость` и другие обычные описания по-прежнему
  блокируются даже когда все игровые заклинания разрешены.

После изменения разрешений останови и запусти распознавание снова.
Перед использованием боевых заклинаний проверь их без игры, включая
посторонние фразы: даже предобученная нейросеть иногда ошибается.


## v1.1.0 — переключаемый русский книжный стиль

Теперь в разделе **«Доступные заклинания»** есть настройка
**«Произношение»**: «Росмэн / книжный стиль» или
«Оригинальные формулы». «Росмэн» включён по умолчанию, даже
если в старом config.json ещё нет поля voice_style.

Зажми Mouse5 (или F9), произнеси одно слово и отпусти. GigaAM
определит русский текст, выбранный словарь сопоставит его с
заклинанием, затем программа отправит настоящее имя для UE4SS:

- Остолбеней → Stupefy
- Вспыхни → Confringo
- Вингардиум Левиоса → WingardiumLeviosa
- Империо → Imperio
- Дезиллюминация → Invisica
- Трансформация → TransfiguraVerto
- Древняя магия → Smash
- Покажи путь → AppareVestigium

«Оригинальные формулы» оставляет прежний словарь; книжные
варианты вроде «Остолбеней» и «Вспыхни» относятся к пресету
«Росмэн». Это книжный *стиль*: часть 28 заклинаний есть
только в игре и не является каноническим текстом перевода.

Проверка микрофона распознаёт все 28 команд без реального
применения. В игре действует отдельный список разрешённых
заклинаний. После смены пресета или разрешений останови и
снова запусти прослушивание.

Важно: **[sent] означает передачу команды в очередь мода, а
не гарантию применения**. Трансфигурации нужна цель, добиваниям
нужны условия игры, а причины отказа UE4SS обычно записывает в
`Phoenix/Binaries/Win64/UE4SS_Logs/UE4SS.log`.

Для обновления можно заменить папку src из свежего архива,
сохранив .venv, config.json и установленную модель GigaAM.
