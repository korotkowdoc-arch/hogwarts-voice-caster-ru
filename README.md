# Hogwarts Voice Caster RU — v0.8.0

**Офлайн-управление заклинаниями в Hogwarts Legacy (Windows).**

Вместо ненадёжных текстовых догадок Vosk по умолчанию используется акустический движок MFCC + DTW. Он сравнивает звучание произнесённого слова с несколькими личными примерами. Неизвестная фраза должна отклоняться, а не превращаться в чужое заклинание. Метод ещё экспериментальный: реальная точность на конкретном микрофоне пока не проверена.

## Установка

1. Windows 10/11 x64, Python 3.11 или 3.12 x64, микрофон.
2. Установи игровой компонент UE4SS из проекта [SpellCaster](https://github.com/pierre-cheneau/HogwartsLegacy-SpellCaster). Оригинальный десктоп-клиент SpellCaster оставь закрытым.
3. Скачай этот проект через Code → Download ZIP, распакуй.
4. Запусти install.bat (при обновлении можно сохранить существующую папку .venv).
5. Запусти run.bat — откроется главное окно без терминала.

## Первый тест: Люмос и Акцио

1. В разделе «Тренировка заклинаний» выбери «Люмос». Нажми кнопку записи, дождись сигнала и произнеси только это слово. Запиши **3–6 образцов**.
2. Повтори для «Акцио». Другие заклинания можно не обучать — они не будут отправляться по голосу.
3. Выбери свой микрофон и нажми «ПРОВЕРИТЬ МИКРОФОН». По пять раз произнеси «Люмос», затем «Акцио». Дополнительно произнеси 3–5 посторонних слов, чтобы проверить ложные срабатывания.
4. В журнале найди строки [rank], [TEST] и [blocked]. [TEST] означает распознавание без отправки в игру; [blocked] — недостаточно уверенное совпадение.

**Важно:** акустические записи предыдущих версий несовместимы с новым движком. Их необходимо записать заново. Старая база не удаляется, но не используется. Новая база: %LOCALAPPDATA%\HogwartsVoiceCasterRU\pronunciation_dtw_v2.json. В ней хранятся числовые признаки голоса, не WAV. Не публикуй этот файл.

## Подключение к игре

После успешного теста открой Hogwarts Legacy (Epic или Steam), загрузи сохранение, затем нажми «НАЧАТЬ КОЛДОВАТЬ» и вернись в окно игры. По умолчанию голосовые команды отправляются только при активной игре. F8 — пауза.

Прямая проверка соединения в PowerShell из папки проекта:

    .\run.bat --send Lumos

Если ответ Lumos: sent, команда передана игровому компоненту. Саму игровую реакцию нужно подтвердить отдельно. Переключатель «Слушать только при активном окне игры» можно временно выключить для диагностики Epic-оверлея, но тогда голос работает и при свёрнутой игре.

## Что делает новый алгоритм

- Берёт аудио блоками около 20 мс, локально, без GPU и облака.
- Обнаруживает речь и ждёт примерно 100 мс тишины, чтобы определить границы произнесённого заклинания.
- Извлекает MFCC и динамические признаки; сравнивает варианты через Dynamic Time Warping (DTW), учитывая разную скорость произнесения.
- Применяет команду только при достаточно высоком сходстве и отрыве от следующего кандидата. Иначе ничего не отправляет.
- Задержка включает время произнесения слова, границу речи, сравнение и реакцию игры. Нулевой задержки физически нет.

Настройки config.json: recognition_engine = acoustic_dtw, dtw_threshold = 0.72, dtw_margin = 0.065. Эти пороги предварительные и требуют оценки на реальном голосе, включая отрицательные примеры. Не снижай их наугад — ложные срабатывания опаснее пропущенных команд. Устаревший Vosk доступен только вручную через recognition_engine = vosk и не рекомендован для магических слов.

## Интерфейс и иконки

Тренировка открывается внутри главного окна. Для оригинальных иконок из игры один раз импортируй ZIP «Spells» с [The Spriters Resource](https://www.spriters-resource.com/pc_computer/hogwartslegacy/asset/494960/). Сами игровые изображения в репозитории не хранятся.

## Разработка и ограничения

Проверка тестов из терминала: PYTHONPATH=src python -m unittest discover -s tests -v. GitHub Actions запускает автоматические тесты на Windows и Linux. Они проверяют код и синтетическое аудио, **не доказывают точность распознавания живой речи**. Если этот эксперимент тоже не выдержит проверки, понадобится специализированная фонетическая KWS-модель с реальным тестовым набором произношений.

Пока требуется установленный внутриигровой мод SpellCaster. Независимый игровой мод и переключаемые профили нескольких людей не реализованы. Код проекта — MIT. Неофициальный фанатский проект.
