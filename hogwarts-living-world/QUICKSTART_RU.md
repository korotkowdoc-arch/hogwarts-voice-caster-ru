# Hogwarts Living World 0.4 — первый запуск (Windows)

Это **техническая тестовая сборка**. В Hogwarts Legacy ещё нет работающих
новых квестов, совиных писем или автоматического управления NPC.

## 1. Скачай архив

GitHub → Actions → «Hogwarts Living World - tests and Windows build» →
последняя **успешная** сборка → Artifacts →
`HogwartsLivingWorld-0.4.0-win64`. Распакуй всё в новую папку вне игры.

## 2. Настрой бесплатный ИИ один раз

Запусти `setup-free.bat`. Введи ключ Gemini или Groq (можно оба).
Они сохраняются в зашифрованном виде для текущего пользователя Windows.
Пожалуйста, **не включай биллинг**, не покупай API-кредиты и не вставляй
ключи в GitHub, скриншоты или чат.

Бесплатные кабинеты:
- https://aistudio.google.com/apikey
- https://console.groq.com/keys

## 3. Запусти мост

Открой `run.bat`. Перейди на ПК в браузере по адресу:

http://127.0.0.1:8765

Увидишь версию, подключённые модели, состояние памяти, пробный диалог
и сюжетный тест. Отправка сообщения ИИ расходует бесплатные квоты,
но платного резервного API в программе нет.

## 4. Проверь устойчивость без игры

Открой `doctor.bat`. Если база цела, в отчёте будет соответствующий статус.
Кнопки сюжетных проверок на веб-панели пишут только в тестовый профиль
`dashboard_demo`, **не** в Hogwarts Legacy.

## 5. Необязательный игровой пробник UE4SS

Сначала сделай резервную копию сохранений и данных Sonorus. Установи
Sonorus **по инструкции автора**, не устанавливая второй UE4SS.

В архиве будет `UE4SS-OPTIONAL/HLWProbe`. При желании скопируй
только эту папку в существующий
`Phoenix/Binaries/Win64/ue4ss/Mods/`.

Для старого UE4SS может потребоваться строка `HLWProbe : 1` в
`Mods/mods.txt`. Никакие другие моды и их файлы не заменяй.

Запусти Hogwarts Legacy, нажми **Ctrl+Alt+F10** и открой
http://127.0.0.1:8765/health. В поле `last_probe` должно появиться
время сигнала — если данная сборка UE4SS поддерживает Lua API и файл
успешно записан. Факт регистрации игрового события этим **не доказан**.
Для удаления достаточно удалить только папку HLWProbe и добавленную
строку в mods.txt (если добавлял).

## 6. Подключение Sonorus

Подробно описано в `SONORUS_SETUP.md`. Основные параметры:

- OpenAI / custom endpoint
- Base URL: `http://127.0.0.1:8765/v1`
- Model: `hogwarts-living-world-free`
- Responses API: выключить
- Vision: выключить
- На первом тесте использовать текстовые диалоги и субтитры

Совместимость со всеми агентами Sonorus и передача реальных игровых
событий остаются **непроверенными** без запуска на игровом ПК.

## Если что-то не работает

Пришли ошибки из `doctor.bat` или Sonorus **без ключей и приватных
данных**. Специально не размещай в GitHub `.env`, `free-keys.dpapi.json`
и содержимое папки `%LOCALAPPDATA%\HogwartsLivingWorld`.

**Платные провайдеры не используются**, но локальные лимиты не могут
предотвратить списание денег, если сам аккаунт провайдера уже
переключён на платный тариф. Для нулевых дополнительных расходов
используй только подтверждённые бесплатные аккаунты без биллинга.
